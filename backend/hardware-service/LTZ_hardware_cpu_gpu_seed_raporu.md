# LTZ Hardware Component Seed Raporu

Bu rapor, oluşturulan iki yeni migration içindeki CPU ve GPU katalog modellerini listeler.

## Migration Dosyaları

- `V69__seed_cpu_components_fresh_catalog.sql`
- `V70__seed_gpu_components_fresh_catalog.sql`

## Kapsam Kuralları

- Intel CPU: Core i3/i5/i7/i9 4. nesilden 14. nesile kadar desktop modeller + Core Ultra desktop modeller.
- AMD CPU: Ryzen 1000 serisinden Ryzen 9000 serisine kadar desktop modeller; APU/G/GE, mobile, PRO ve Threadripper hariç.
- NVIDIA GPU: GTX 10 serisinden RTX 50 serisine kadar desktop GeForce modeller; laptop/workstation/Titan hariç.
- Intel GPU: Arc A-Series ve Arc B-Series desktop modeller.
- AMD GPU: Radeon RX 5000 serisinden RX 9000 serisine kadar desktop modeller; mobile/workstation hariç.

## Notlar

- Bu dosyalar `hardware_components` tablosunu kullanır; ayrı fiziksel CPU/GPU tablosu oluşturmaz. Ayrım `component_type` ve `category` üzerinden yapılır.
- Dosyaların başındaki `DELETE` satırları local geliştirme/reset senaryosu için eklendi. Canlı veride kullanıcı donanımı CPU/GPU kayıtlarına FK ile bağlıysa bu satırlar FK hatası verebilir.
- Eğer eski V69/V70 seed dosyalarını projede tutacaksan bu dosyaları V71/V72 olarak çalıştır. Eski seed dosyalarını sileceksen dosya numaralarını V69/V70 olarak yeniden adlandırabilirsin.
