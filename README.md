# game-app
Oyuncuların oyun keşfi yapabildiği, inceleme ve puanlama paylaşabildiği, arkadaş bulabildiği, donanım bilgilerine göre öneriler alabildiği ve topluluk etkinliklerine katılabildiği sosyal oyun platformu. Yapay zekâ destekli öneriler, profil yönetimi ve oyun topluluğu özelliklerini tek çatı altında toplar.
